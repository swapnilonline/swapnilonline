# The Recurring Income Blueprint

Two-page PDF at `public/recurring-income-blueprint.pdf`. Edit `recurring-income-blueprint.html`, then re-render:

```bash
cd docs/formula && "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="$PWD/../../public/recurring-income-blueprint.pdf" --virtual-time-budget=8000 "file://$PWD/recurring-income-blueprint.html"
```

Fonts are shared from `../blueprint/fonts/`.
